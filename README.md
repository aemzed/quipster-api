# Quipster API

Shared backend for a set of startup POS/CRM products — Quipster POS, Wooblazz CRM, plus stock, sales, employee, and WhatsApp broadcast (Watzap) modules.

## Stack
Node.js · TypeScript · Express · Prisma · MySQL · node-cron

## Run locally
```bash
npm install
npm run dev
```

Set database connection in `config/connect`. API listens on port `3003`.
